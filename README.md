# ShopNest BD — E-commerce Starter

এটি একটি responsive e-commerce/dropshipping frontend starter।

## চালু করা
1. ZIP extract করুন।
2. `index.html` খুলুন অথবা GitHub Pages-এ repository publish করুন।
3. `admin.html` ডেমো admin panel।

## গুরুত্বপূর্ণ
এই version-এ cart, wishlist, account demo এবং admin data browser `localStorage`-এ থাকে।
বাস্তব ব্যবসার জন্য এগুলো নিরাপদ backend/database দিয়ে বদলাতে হবে:
- Authentication
- Product database
- Order database
- Payment gateway
- Admin authorization
- Image/file storage
- Server-side price/stock validation

GitHub Pages শুধুমাত্র static frontend hosting-এর জন্য উপযোগী। Real orders/payment-এর জন্য Supabase/Firebase বা নিজস্ব backend যোগ করুন।
